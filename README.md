# Finance-Analysis-Dashboard-Power-BI
This project presents an interactive Finance Analysis Dashboard built in Power BI to help monitor key financial metrics, identify trends, and support data-driven business decisions. The dashboard provides a clear overview of financial performance through dynamic visualizations and KPI tracking.

# Key Insights and Features
•	Executive KPI Dashboard (Total Amount, Transactions, Average Transaction Value, Fees & Tax)
•	Monthly Financial Trend Analysis
•	Transaction Status Analysis (Success, Failed & Pending)
•	Customer Segment Performance Analysis
•	State-wise Revenue Distribution
•	Transaction Type Analysis
•	Gender-based Revenue Insights
•	Interactive Slicers (Year, Category, Occupation & Dynamic Metrics)
•	Detailed Transaction-Level Report
